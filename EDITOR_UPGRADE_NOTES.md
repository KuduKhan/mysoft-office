# MySoft Office: professional editor expansion

Reviewed 25 October 2026. MySoft remains an independent, local-first suite. These are implemented workflows, not a claim of full commercial-suite parity.

## Advanced Studio — 25 October 2026

| App | Working addition | Supported behavior and limits |
| --- | --- | --- |
| Docs | Advanced text replacement | Literal find text, optional match-case and Unicode-aware whole-word boundaries, read-only preview, and explicit apply. Matches can span inline formatting within leaf text blocks. Starting character formatting is retained; replacement is inserted as text. Supports Undo/Redo and save/reopen. Limits: 500-character query, 2,000-character replacement, 1,000 matches and one-million-character output. Does not replace image descriptions, metadata or matches across separate paragraphs. |
| Sheets | Goal Seek | Solve one formula result by changing one numeric input. A bounded bisection solver previews the proposed value; apply changes only that input. Existing formulas and other values remain intact. Defaults locate an existing formula and numeric cell. Bounds must bracket the target within ±1 billion; use continuous formulas with a suitable solution in the interval. Up to 100 iterations, tolerance max(1e−8, abs(target) × 1e−8). Discontinuous or nonconvergent results are rejected. This is not multi-variable optimization. |
| Slides | Roadmap builder | Append a new designed slide containing 3–6 independent editable milestone-card shapes, with title and custom color. Labels are limited to 80 characters each; the title to 120. Cards fit within normalized slide bounds, use contrasting text, and retain supported shape edit/export workflows. Balanced rows and a dedicated native heading position keep the title clear of the cards; Office imports retain the supported text/object subset. Existing slides remain intact. |
| Notes | Combine full notes | Select 2–10 notes in listed order and create an independent note with all body content and optional source headings. First-source notebook, section and canvas settings are copied; tags are combined, capped at 20. Original notes remain intact. Atomic new-file save and retry behavior reuse Production Studio. Maximum body: one million characters. |
| PDF | Standardize page size | Export one A4 or Letter sheet per output page, in portrait or landscape, with 12–60 pt margins. Vector page content is centered and fitted while respecting existing rotations and crop boxes. Current output order is retained; source bytes remain intact. Up to 200 output pages. Interactive annotations and form fields are not copied. |
| Media | Distribute visible drawing layers | Equal horizontal or vertical gaps between point bounds of three or more visible, non-eraser drawing layers. Keeps endpoints, layer order, shape geometry, styles, hidden layers and erasers intact. Negative-gap or out-of-canvas arrangements are refused before editing. Supports Undo/Redo and saved geometry. Does not rearrange source photo/video pixels. |

Primary workflow references: [Microsoft advanced replacement](https://support.microsoft.com/en-us/word/training/find-and-replace-text-in-word), [Microsoft Goal Seek](https://support.microsoft.com/en-au/excel/use-goal-seek-to-find-the-result-you-want-by-adjusting-an-input-value), [Adobe page scaling](https://helpx.adobe.com/uk/acrobat/kb/scale-or-resize-printed-pages.html), and [Canva alignment workflows](https://www.canva.com/help/layer-group-align/). Implementations are independent MySoft tools.

## Ribbon workbench — 25 October 2026

- **All six editors:** content-sized groups, separate object alignment/position/transform/layer groups, labels, group-jump dropdown, previous/next overflow controls, and saved compact/comfortable ribbon density. Each ribbon has one bounded scrolling stage; groups have no nested scrolling. Category switches reset scroll position while retaining the editor and text selection. Alt+R focuses the active task tab or native ribbon group selector.
- **PDF and Media:** original delegated controls are moved into labeled ribbon groups without replacing editor content or IDs. Their ribbon tools can be collapsed independently and reopened after reload. PDF fit views respond to viewport-size changes caused by ribbon layout changes.
- **Docs and Notes:** justify, Heading 3, and selected-paragraph indentation/outdent in 16px increments, bounded to 0–96px. Indentation saves in the native file and HTML export; supported Office-format export retains its separately documented subset. Bold/italic/underline/list controls expose the current selection state. Notes gains a dedicated Insert category for tables, pictures, links, checklists, dates, quotes and dividers.
- **Sheets:** Auto SUM/AVERAGE/MIN/MAX/COUNT requests a source range and refuses occupied result cells or a result inside that range. Source ranges retain the existing 2,600-cell operation limit. General number format clears the currency/percent format without discarding other cell styling.
- **Slides:** first/last-slide shortcuts and a separate Present from beginning action. The existing Start presentation action continues from the selected slide.
- **PDF:** first/last output-page navigation, Fit height, and stepped zoom. Page ends follow the current reordered/duplicated page sequence.
- **Media:** Save preview PNG exports a composition as PNG or the current audio waveform as PNG. Reset canvas view and stepped zoom adjust the view without changing saved project content. Existing image, audio and video output workflows remain available.

## Supplied MO reference adaptation

The reference project's neutral surfaces, full-width editor organization and labeled ribbon groups are adapted to the existing six-app architecture. Reference source files remain unchanged. The four-color MySoft mark and native app colors are retained. Editors offer File navigation, appearance settings and keyboard-navigable task tabs. Supporting panels remain optional; empty document outlines collapse automatically. PDF tools use a side panel on desktop and a bounded panel on phones.

Home and optional Files grid previews show actual saved content. Grid/list preference persists on this device; Trash retains its recovery controls. Docs Layout adds bounded paragraph spacing, first-line indentation, letter spacing and left/right text direction, applied to selected paragraphs or the document when no selection exists. Inline formatting is retained. Notes Design saves paper, typography, spacing, writing width and ruled guides with each note without rewriting its content. These canvas choices do not impose formatting on plain text or Markdown exports.

## Further editing tools

- **Docs → Tools → Table designer:** style an existing table, choose header color, convert the first row into semantic headers, align text and apply alternating row fills. Cell content and spans are retained. Header text automatically switches between white and black for contrast. Changes participate in document history and workspace saves; Office-format export keeps its documented supported subset.
- **Sheets → Tools → Filter to new sheet:** extract matching rows by text, numeric comparison, blank or nonblank criteria. Results are computed-value snapshots; the original formulas and data stay in their worksheet. No-match and unsafe-text errors do not create a result sheet.
- **Slides → Tools → Repeat object grid:** repeat the selected object into a grid with independently editable objects, row/column counts and horizontal/vertical gaps. The entire grid is validated against slide bounds and the 40-object limit before mutation. Source rotation must be zero; set it using Object properties.
- **Notes → Tools → Import/Export Markdown:** append a supported Markdown subset with headings, paragraphs, lists, checkboxes, bold, italics and HTTP(S) links; export headings, lists, tasks, emphasis, quotes and basic tables. Raw HTML is imported as text. This is a bounded subset, not a complete CommonMark implementation; image data stays in the workspace and exports as an image-description placeholder.
- **PDF → Merge PDFs and export:** append selected PDFs to the currently ordered and rotated pages, then download a separate merged copy. Workspace files remain intact. Up to 10 appended PDFs, 8 MB per source, 32 MB combined source data and 500 output pages. Password-protected files are unsupported; this copies page content rather than merging document-level forms/bookmark structures. A merged file larger than 8 MB may exceed the workspace re-import limit.
- **Media → Canvas:** add a vignette, frame width and frame color. Effects appear in raster images, video frames/video export and SVG drawing output, and support existing undo/redo and persistence. Very small canvases clamp frame width to their dimensions.
- **Find tools / Ctrl+K:** arrow keys move through filtered results, Home/End jump within results, Enter runs the selected command, and Arrow Up from the first result returns to search.

The new folded-M logo uses the suite's blue, green, orange and purple colors. The sidebar, editor surfaces, dialog layouts and tool states share a restrained contemporary finish. New tools are included in the existing **Ctrl+K / Find tools** directory; compact mobile layouts remain available.

## Product benchmarks

These official references informed the workflow priorities. The implementations are MySoft code and use locally bundled libraries.

- [Microsoft: PivotTables and PivotCharts](https://support.microsoft.com/en-us/excel/overview-of-pivottables-and-pivotcharts) and [WPS: analyzing data with pivot tables](https://www.wps.com/academy/how-to-analyze-data-using-pivot-tables-in-wps-office-excel-quick-tutorials-1862890/) informed grouped summaries and preservation of source data.

- [CorelDRAW: SVG](https://help.coreldraw.com/CorelDRAW/540111192/Documentation-Windows/CorelDRAW-en/CorelDRAW-Scalable-Vector-Graphics-SVG.html) informed scalable drawing output with paths, shapes and text.
- [Canva: editing photos](https://www.canva.com/help/image-editor/) informed contextual editing and a clear distinction between source media and output adjustments.

## Further engineering scope

Real-time collaboration, cloud synchronization, full Office-format fidelity, OCR, true PDF text editing/redaction, advanced charting, full slide masters and animations, vector node editing, and multi-track media timelines require further implementation and validation. They are not advertised as available tools.
