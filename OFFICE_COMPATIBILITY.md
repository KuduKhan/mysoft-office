# MySoft Office v0.5 — Office format interoperability

MySoft Office now supports importing and exporting **real Open XML files**: DOCX, XLSX and PPTX. It uses ZIP packages with standard XML parts, content types and relationships. This is limited, semantic interoperability—**not full Microsoft Office format fidelity**.

## Supported functionality

| Format | Imported as editable | Exported from MySoft | Known losses |
|---|---|---|---|
| DOCX | Paragraphs, basic headings, bold, italic, underline, simple tables | Paragraphs, headings, inline emphasis and tables | Images, comments, tracked changes, links, advanced styles, section layout, complex tables |
| XLSX | Up to 20 sheets, A1:Z1000, text/numbers, formulas, basic font and fill styles | Same | Pivot tables, data validation, images, charts, conditional formatting, merged cells, unsupported formulas and links |
| PPTX | Up to 200 slides, title and body text extracted as editable content | Editable title/body text and MySoft rectangle/ellipse/text boxes | Exact layout, animations, pictures, shapes, notes, media, masters and charts |

An import confirmation screen always warns that unsupported content may be lost on re-export. Exporting through the DOCX, XLSX or PPTX control also discloses limitations. Files are read locally, converted into new MySoft files, and do not modify the source.

Use **Export backup** separately when you need a full-fidelity backup of MySoft-specific metadata and versions.

## Workflow

1. Choose Import file in the sidebar, select a .docx, .xlsx or .pptx file, then review the conversion warning.
2. Confirm import to create an editable MySoft file.
3. Make edits using the existing Docs, Sheets or Slides tools.
4. Use the new DOCX/XLSX/PPTX export control in the editor header.
5. Review the export warning and download the native package.

## Supported package boundaries

The parser limits archives to 18 MB compressed and 24 MB uncompressed, 180 parts, and rejects unsafe paths, duplicate entries, encrypted ZIPs, ZIP64, excessive compression ratios, or unsupported XML entities. STORE and DEFLATE ZIP entries are supported. Macro-enabled Office types are not imported.

Limits are protective, not a guarantee against all malicious files. Do not use this prototype for classified, sensitive military or regulated data.

## Independent validation

Browser tests create and re-import native packages, and open compressed files generated by python-docx, openpyxl and python-pptx. GitHub Actions additionally opens MySoft-generated files with these independent readers. These tests verify representative cases; manual review in Microsoft Word, Excel and PowerPoint remains necessary for formatting fidelity and edge cases.

## Architecture

- src/ooxml-zip.js — ZIP/Open Packaging Conventions, safe XML, relationship resolution.
- src/ooxml-docx.js — WordprocessingML adapter.
- src/ooxml-xlsx.js — SpreadsheetML adapter.
- src/ooxml-pptx.js — PresentationML adapter.
- tests/e2e/ooxml.spec.cjs — browser import/export and compatibility cases.
- scripts/make_office_fixtures.py, scripts/check_ooxml.py — external format fixtures and validations.

## Open work for professional equivalence

Replace the contenteditable editor with a structured editing model, expand workbook data and formulas, add precise shape-based slide layouts, support native images/objects/charts/notes, add deep format-roundtrip regression fixtures, and move storage to a durable secured backend. Do not label MySoft fully compatible with Microsoft Office until those tests and features exist.

## v0.5.6 conversion notice

- **PPTX:** MySoft simple rectangles, ellipses and text boxes export and import their positions and quarter-turn rotations through DrawingML. Complex native PowerPoint rotations, images, animations and unsupported shapes are still lossy.
- **XLSX:** MySoft worksheet conditional-formatting rules are stored in MySoft local files/JSON backups, **not** in XLSX output. Review original conditional styles after export.
- **DOCX:** local find navigation, review annotations, advanced pagination and section metadata do not have complete DOCX round-trip fidelity.
- **Notes:** pinned-note metadata is kept in MySoft local workspace and JSON backup, not in Office document formats.

## v0.6.2 supported additions and boundaries

- DOCX export remains limited to semantic paragraphs/headings/basic inline styles and simple tables. The new heading style actions use H1/H2 and may round-trip; unsupported quotes, layouts, comments and advanced typography require manual review.
- XLSX exports numeric calculation expressions as formula text; IF/AND/OR/NOT and numeric comparisons may be evaluated inside MySoft, but exact formula semantics, caches and third-party reader compatibility are **not guaranteed** for arbitrary workbooks.
- PPTX round-trips supported MySoft rounded rectangles and triangle objects using DrawingML preset geometries. Third-party SVG, media, rich shape fills and animations are not preserved.


## v0.8.0 fidelity boundaries
- DOCX: Manual contents refresh works in MySoft but is not a native Word field-code or page-aware TOC.
- XLSX: Relative references copied within A1:Z1000 are shifted; absolute/cross-sheet references and unsupported functions remain restricted.
- PPTX: Diamond and hexagon objects round-trip for supported MySoft preset geometry; images, complex charts, masters and animations remain incomplete.
- PDF: MySoft source-page bookmarks are workspace metadata, **not** embedded PDF bookmarks, annotations or cryptographic signatures.
- Media: Compare original is a transient preview-only mode that never overwrites the source or current edit settings.


## v0.8.1 — Safe links and speaker notes
- DOCX export uses external hyperlink relationships for valid HTTP(S) URLs only (up to 250 unique links), including hyperlinks in simple tables. DOCX import resolves external hyperlink relationship IDs and retains supported inline bold/italic/underline/strike/superscript/subscript runs. Local MySoft links, internal Word anchors, complex hyperlink fields, untrusted schemes and advanced run properties are **not** preserved; link text remains visible with warnings.
- PPTX export writes plain-text speaker notes as Notes Slide parts and their associated Notes Master relationship. Import restores text from related notes body placeholders, including third-party PPTX notes. Note formatting, images, complex text frames and theme fidelity remain outside the supported subset.
- PPTX export explicitly rejects packages over the safe importer limit of 180 parts; this can constrain large slide decks, especially with speaker notes.
- PDF bookmarks clicked before PDF.js completes opening now select the desired source page upon load. Bookmark data still remains inside MySoft workspace/backup files, not PDF exports.
