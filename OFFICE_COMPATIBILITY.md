# MySoft Office v0.5 — Office format interoperability

MySoft Office now supports importing and exporting **real Open XML files**: DOCX, XLSX and PPTX. It uses ZIP packages with standard XML parts, content types and relationships. This is limited, semantic interoperability—**not full Microsoft Office format fidelity**.

## Supported functionality

| Format | Imported as editable | Exported from MySoft | Known losses |
|---|---|---|---|
| DOCX | Paragraphs, basic headings, bold, italic, underline, simple tables | Paragraphs, headings, inline emphasis and tables | Images, comments, tracked changes, links, advanced styles, section layout, complex tables |
| XLSX | Up to 20 sheets, A1:Z1000, text/numbers, formulas, basic font and fill styles | Same | Pivot tables, data validation, images, charts, conditional formatting, merged cells, unsupported formulas and links |
| PPTX | Up to 200 slides, title and body text extracted as editable content | Title/body text on editable slides | Exact layout, animations, pictures, shapes, notes, media, masters and charts |

An import confirmation screen always warns that unsupported content may be lost on re-export. Exporting through the DOCX, XLSX or PPTX control also discloses limitations. Files are read locally, converted into new MySoft files, and do not modify the source.

Use **Export backup** separately when you need a full-fidelity backup of MySoft-specific metadata and versions.

## Workflow

1. Choose Import file in the sidebar, select a .docx, .xlsx or .pptx file, then review the conversion warning.
2. Confirm import to create an editable MySoft file.
3. Make edits using the existing Docs, Sheets or Slides tools.
4. Use the new DOCX/XLSX/PPTX export control in the editor header.
5. Review the export warning and download the native package.

## Supported package boundaries

The parser limits archives to 18 MB compressed and 24 MB uncompressed, 180 parts, and rejects unsafe paths, duplicate entries, encrypted ZIPs, ZIP64, excessive compression ratios, or unsupported XML entities. STORE and DEFLATE ZIP entries are supported. Macro-enabled Office types are not imported.

Limits are protective, not a guarantee against all malicious files. Do not use this prototype for classified, sensitive military or regulated data.

## Independent validation

Browser tests create and re-import native packages, and open compressed files generated by python-docx, openpyxl and python-pptx. GitHub Actions additionally opens MySoft-generated files with these independent readers. These tests verify representative cases; manual review in Microsoft Word, Excel and PowerPoint remains necessary for formatting fidelity and edge cases.

## Architecture

- src/ooxml-zip.js — ZIP/Open Packaging Conventions, safe XML, relationship resolution.
- src/ooxml-docx.js — WordprocessingML adapter.
- src/ooxml-xlsx.js — SpreadsheetML adapter.
- src/ooxml-pptx.js — PresentationML adapter.
- tests/e2e/ooxml.spec.cjs — browser import/export and compatibility cases.
- scripts/make_office_fixtures.py, scripts/check_ooxml.py — external format fixtures and validations.

## Open work for professional equivalence

Replace the contenteditable editor with a structured editing model, expand workbook data and formulas, add precise shape-based slide layouts, support native images/objects/charts/notes, add deep format-roundtrip regression fixtures, and move storage to a durable secured backend. Do not label MySoft fully compatible with Microsoft Office until those tests and features exist.
